# 📝 Keep Notes

A modern and responsive notes management web application inspired by Google Keep, built with **React and Vite**.

Keep Notes allows users to quickly create, organize, search, edit, pin, and delete notes with different colors. Notes are stored in the browser using `localStorage`, so they remain available even after refreshing the page.

---

## 🚀 Live Demo : https://keep-notes-silk.vercel.app/

---

## 📌 About The Project

**Keep Notes** is a frontend notes management application designed for simple and fast note-taking.

The project was created to practice modern frontend development using React, component-based UI development, responsive design, browser storage, and Vite.

---

## ✨ Features

- 📝 Create new notes
- ✏️ Edit existing notes
- 🗑️ Delete notes
- 📌 Pin important notes
- 🔍 Search notes
- 🎨 Choose different note colors
- 💾 Save notes using browser `localStorage`
- 🌙 Dark mode
- 📱 Responsive design
- ⚡ Fast development with Vite
- 🖥️ Clean and modern user interface
